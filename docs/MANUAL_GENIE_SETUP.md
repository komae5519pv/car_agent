# Genie Space 手動設定（パイプライン実行後）

パイプライン（`databricks bundle run setup_demo`）は 3 つの Genie Space を作成しテーブルを紐付けますが、以下の 2 項目は**現在の Databricks API で設定不可**のため、**UI から手動で追加**する必要があります：

1. **一般的な指示**（Genie の振る舞いを決めるプロンプト）
2. **UC 関数の登録**（`current_sales_rep_email()` の curated tools 登録）

> なお、UC 関数 `current_sales_rep_email()` 自体はパイプラインが UC に作成しており、テーブル経由でスキーマに可視です。UI で「Curated functions」に登録しなくても、Genie が instruction を通じて呼び出せる可能性は高いですが、明示登録すると確実性が増します。

## 対象 Genie Space（3つ）

パイプライン完了後、以下の 3 つが作成されます。Databricks UI の Genie タブから開いてください。

| # | 表示名 | 用途 |
|---|---|---|
| 1 | `[car-agent] 車両営業アシスタント` | Ask AI（MAS 経由） |
| 2 | `[car-agent] 営業マイページ` | アプリのマイページの「AI に聞く」 |
| 3 | `[car-agent] 営業データ` | AI/BI ダッシュボード連携 |

## 手順

各 Genie で次の 2 ステップを実施：

### Step 1. 一般的な指示を貼る

1. Genie Space を開く
2. 右上「設定」→「Instructions」タブ → 「一般的な指示」
3. 下記コードブロックの本文を**コピー＆ペースト** → 保存

### Step 2. UC 関数を登録

1. 同じ「設定」内「Functions」タブ
2. 「関数を追加」 → `konomi_demo_catalog.car_agent.current_sales_rep_email` を選択 → 保存

（カタログ/スキーマを書き換えている場合は自分の値に読み替え）

## 各 Space に貼る指示本文

### ① `[car-agent] 車両営業アシスタント`

```
あなたは中古車販売の営業アシスタントです。
営業担当者からの質問に対し、顧客データ・在庫データ・商談履歴を参照して回答します。
営業担当者の「自分」は current_sales_rep_email() を呼んで取得したメールアドレスで sv_customers.sales_rep_email と照合してください。

主な対応範囲:
- 顧客の購入履歴・嗜好・予算に基づく車両提案
- 在庫車両の検索・絞り込み（車種、価格帯、年式、走行距離など）
- 商談進捗の確認と次のアクション提案
- 顧客インサイト（購買傾向、おすすめ車両）の参照

回答のルール:
- 顧客名は「苗字＋様」で表記してください
- 金額は日本円（万円単位）で表示してください
- 在庫状況は最新データを参照してください
- 不明な場合は「該当データが見つかりません」と回答してください
```

### ② `[car-agent] 営業マイページ`

```
あなたは中古車販売の営業成績アナリストです。
営業担当者の売上実績・目標達成率・商談状況を分析し、回答します。
「自分の成績」などログインユーザーを指す問いは current_sales_rep_email() のメールアドレスを sv_sales_results.sales_rep_email と照合してください。

主な対応範囲:
- 個人の売上実績と目標達成率の確認
- 期間別（月次・四半期・年次）の成績推移
- 同僚との比較・ランキング
- 成約率・商談単価の分析

回答のルール:
- 営業担当名は「苗字＋様」で表記してください
- 金額は日本円（万円単位）で表示してください
- 達成率はパーセントで表示してください
- ポジティブな表現を心がけてください
```

### ③ `[car-agent] 営業データ`

```
あなたは中古車販売の営業データアナリストです。
店舗別の売上・ファネル転換率データを分析し、経営層や店舗マネージャーの質問に回答します。

主な対応範囲:
- 店舗別・地域別の売上実績と比較
- ファネル転換率（問合せ→試乗→見積→成約）の分析
- 月次・四半期トレンドの把握
- 車種カテゴリ別の販売傾向

回答のルール:
- 金額は日本円（万円単位）で表示してください
- 転換率はパーセントで表示してください
- グラフや表での表示を積極的に活用してください
- データに基づいた改善提案も添えてください
```

## 動作確認

各 Genie で以下のクエリを試すと動作確認できます：

- ①②: 「自分のメールは？」 → `current_sales_rep_email()` が呼ばれ、ログインユーザーのメールが返る
- ①: 「田中様に合う SUV は？」 → 顧客インサイト・在庫を統合した推薦
- ②: 「今月の成績は？」 → 自動的にログインユーザーの成績を返す
- ③: 「今月の店舗別売上ランキングを見せて」
